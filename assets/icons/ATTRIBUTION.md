# Category icons

SVG icons from [Lucide](https://lucide.dev), Lucide Icons and Contributors.

Source: https://github.com/lucide-icons/lucide/tree/0.468.0/icons

Icons: cog, cpu, eye, flame, swords, shield, sword, orbit, crown, library-big, skull, music, headphones, book-open, folder.

The SVG originals in this directory are unmodified. `category-icons.js` embeds their geometry with common decorative SVG attributes for offline use.
