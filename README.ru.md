# MeguBoom

**Личный плеер музыки и аудиокниг для Windows и Android.**

[English](README.md) · [Подробная инструкция](docs/ru/USER_GUIDE.md) · [English guide](docs/en/USER_GUIDE.md)

Windows **0.6.1** · исходники Android **0.4.1**. Интерфейс приложения сейчас русский. Документация опубликована на двух языках.

- ПК: локальные файлы, Google Диск, папки, список/сетка, поиск, избранное, плейлист и очередь.
- Android: одна выбранная папка Google Диска со вложенными папками; музыка, книги и неразобранные записи; офлайн-копии.
- Общие позиции и отметка «Прослушано» через Google Диск; сохранение изменений без сети. Удалённые обновления не перематывают играющую запись.
- Скорость, таймер сна, короткая перемотка, мини-плеер и полный плеер, управление через уведомление Android.

## Установка

Публичный установщик Windows находится в [Releases](https://github.com/q9605514048-prog/MeguBoom/releases). Для запуска из исходников нужны Windows и Node.js22+:

```powershell
npm ci
npm test
npm start
npm run build:win
```

**[Пошаговая инструкция](docs/ru/USER_GUIDE.md)** описывает настройку Google Cloud, сборку Android, папку Диска, синхронизацию, управление и частые проблемы. Инструкция находится в документации, а не внутри приложения.

## Публичная версия

Личное аудио, каталог пользователя, токены, OAuth JSON, ключи подписи Android и ID личных папок исключены. Используется оригинальная нейтральная иконка. Без собственных метаданных описания и обложки могут отсутствовать. Для Android необходимо указать свою папку, собрать APK и зарегистрировать приложение в своём проекте Google Cloud; готового Android APK в публичном релизе нет.

Нужны один аккаунт и проект Google на обоих устройствах и подтверждение разрешений. Реальный обмен между физическим телефоном и ПК после подтверждения ещё требует проверки пользователем. [Результаты проверок](docs/ru/VERIFICATION.md).
