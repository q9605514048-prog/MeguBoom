Подключи свою облачную библиотеку

Вход в Google нужен только для доступа к твоим файлам. Пароль приложение не получает.

Первое подключение: где взять OAuth JSON
  1. В Google Cloud Console создай проект и включи Google Drive API.
  2. Настрой экран согласия OAuth. Для личного тестирования добавь свой Google-аккаунт в Test users.
  3. Создай OAuth client ID типа Desktop app и скачай его JSON.
  4. Выбери JSON здесь и нажми «Подключить Google». Разрешение подтверждается в браузере.

Доступ: чтение аудиофайлов, создание собственных загрузок в папке MeguBoom и хранение прогресса прослушивания в скрытой папке приложения Google Диска. На ПК и Android нужен один Google-аккаунт. При первом включении синхронизации переподключи Google, чтобы разрешить хранение прогресса. JSON и токены хранятся в защищённом хранилище Windows.

Аудиофайлы передаются по мере прослушивания.

О приложении

MeguBoom · Personal Cloud Player

Музыка и аудиокниги из твоих файлов на компьютере и Google Диске через Google Drive API. Приложение не ищет записи на сторонних сайтах.

Личная библиотека

Условия использования

Твои файлы и данные

Локальные файлы остаются на твоём компьютере. Файлы Google Диска передаются по запросу; приложение не загружает весь Диск автоматически. При добавлении локальной папки сохраняются ссылки на файлы. Скачанные записи помещаются в папку MeguBoom на ПК.

Доступ к Google

Авторизация проходит в браузере Google. OAuth JSON и токены шифруются средствами Windows и не передаются в интерфейс плеера. Можно отключить аккаунт в разделе Google Диска.

Личная медиатека

Ты самостоятельно находишь и добавляешь музыку и аудиокниги. Приложение воспроизводит файлы только с компьютера и Google Диска через Google Drive API. Сторонние музыкальные каталоги не подключены.

Используй файлы, к которым у тебя есть доступ, с соблюдением условий их использования.
