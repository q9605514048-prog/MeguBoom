# MeguBoom: установка и использование

[English guide](../en/USER_GUIDE.md) · [Проект](../../README.ru.md)

## 1. Какую версию выбрать

Windows: скачайте установщик MeguBoom-Public-Setup из Releases и запустите его. В публичной версии нейтральная оригинальная иконка и пустой каталог. Можно также запустить исходники, см. раздел7.

Android: публичный релиз содержит исходники, а не настроенный APK. Авторизация Google связывает пакет и сертификат приложения с вашим проектом Google Cloud. Сборка для своей папки описана ниже. Личные установщики уже настроенных частных версий сохраняйте отдельно: публичный установщик использует то же имя приложения и может заменить личную версию.

Аудиофайлов в репозитории нет. Используйте файлы, к которым у вас есть право доступа. Интерфейс приложения сейчас русский.

## 2. Подготовка Google Cloud

1. Откройте [Google Cloud Console](https://console.cloud.google.com/), создайте или выберите проект. Включите **Google Drive API**.
2. В Google Auth Platform заполните Branding и Audience. Если приложение в режиме тестирования, добавьте используемый Google-аккаунт в тестовые пользователи.
3. В Data Access настройте разрешения, которые запрашивает приложение: **drive.readonly**, **drive.file** (загрузка файлов с ПК), **drive.appdata** (скрытые записи прогресса).
4. В Clients создайте OAuth-клиент типа **Desktop app**. Скачайте JSON и храните на своём устройстве. Не добавляйте его в GitHub и не передавайте другим пользователям.
5. Для Android используйте тот же проект. Имя пакета: **ru.meguboom.mobile**. Зарегистрируйте **SHA-1** сертификата, которым подписан именно ваш APK. Desktop JSON не заменяет регистрацию пакета и сертификата Android.

Официальные материалы: [настройка Drive OAuth](https://developers.google.com/workspace/drive/api/quickstart/nodejs), [авторизация Android](https://developer.android.com/identity/authorization), [данные приложения](https://developers.google.com/workspace/drive/api/guides/appdata).

## 3. Подключение на ПК

1. Запустите MeguBoom → **Google Диск** в боковой панели.
2. Нажмите **Выбрать OAuth JSON**, выберите JSON клиента Desktop app и затем **Подключить Google**.
3. Подтвердите вход в системном браузере и вернитесь в приложение. Если панель прогресса просит новое разрешение, переподключите Google.
4. Укажите свою папку в поле ID/ссылки на папку. Можно вставить ссылку Google Диска. Личная папка автора не включена в публичную версию.
5. Выберите книги или музыку и открывайте вложенные папки. Воспроизведение передаёт звук по сети, не скачивая весь Диск. Кнопка скачивания сохраняет копию на ПК; загрузка локального файла создаёт его копию в папке MeguBoom на Диске.

Токены на ПК шифруются защищённым хранилищем Windows. Отключить аккаунт можно в разделе Диска.

## 4. Настройка, сборка и подключение Android

Нужны Node.js 22+, JDK 17, Android SDK (платформа36 и build tools), сервисы Google Play на телефоне. Исходники поддерживают Android8/API 26+. SDK можно установить через Android Studio. Задайте ANDROID_HOME или создайте не публикуемый android/local.properties с sdk.dir для своего компьютера.

Из корня репозитория:

~~~powershell
npm ci
node scripts/configure-drive-folder.cjs "https://drive.google.com/drive/folders/YOUR_FOLDER_ID"
npm run stage:android
cd android
.gradlew.bat testDebugUnitTest lintDebug assembleDebug
.gradlew.bat signingReport
~~~

Команда настройки меняет папку одновременно в нативном коде и интерфейсе. При смене папки повторите настройку и подготовку ресурсов. APK: **android/app/build-mobile-drive/outputs/apk/debug/app-debug.apk**. Отладочная подпись подходит для личной разработки. Не публикуйте ключи. Для обновления поверх старой версии нужен прежний сертификат; при смене сертификата Android потребует удалить старую версию. В Google Cloud укажите SHA-1 своей сборки из signingReport.

Установите APK на телефон. В настройках выберите JSON из того же проекта Google и нажмите **Подключить Google Диск заново**. Импорт JSON определяет проект, а вход выполняется нативно через сервисы Google Play. Приложение открывает только заданную папку и её вложенные папки. Музыка, аудиокниги и неразобранные файлы разделены. Произвольный импорт файлов телефона и общий «Мой Диск» в этом режиме Android недоступны.

## 5. Включение синхронизации

1. Используйте один Google-аккаунт на обоих устройствах и OAuth-клиенты из одного проекта.
2. Переподключите Google на ПК и телефоне, подтвердите разрешение на данные приложения. Создавать файл прогресса вручную не нужно.
3. Нажмите **Синхронизировать / Синхронизировать сейчас**. Прослушайте файл на одном устройстве, поставьте паузу, синхронизируйте второе и откройте тот же файл Google Диска.

Передаются позиция и отметка «Прослушано». Записи связываются по исходному Google fileId, включая проверенные скачанные копии. Одинаковые названия не объединяют разные файлы. Обычный интервал обмена — около 30 секунд; пауза, перемотка и завершение также запускают синхронизацию. Без сети изменения сохраняются локально и отправляются позже при работающем приложении. Удалённое обновление не перематывает играющую запись. Если оба устройства изменяли один файл, побеждает более позднее время изменения, включая перемотку назад и снятие отметки. Проверьте правильность системного времени.

Избранное, плейлисты, громкость и произвольные локальные файлы не синхронизируются. Повторная загрузка файла на Диск создаёт новый ID: это не обязательно прежняя запись прогресса. Токенов в файле прогресса нет.

## 6. Управление и частые проблемы

- **Добавить файлы / Добавить папку** на ПК включает локальное аудио в библиотеку, не перемещая оригиналы.
- Нажмите папку, чтобы увидеть содержимое. Числовой порядок сохраняется. Для возврата используйте путь папок или кнопку «Назад».
- В карточке книги находятся обложка, автор, описание и отметка завершения. Публичный каталог пустой: при отсутствии метаданных используются заглушки.
- Мини-плеер доступен во время навигации. Откройте его для полного управления, очереди, скорости, короткой перемотки и таймера сна.
- Сердце добавляет в избранное; **Отметить прослушанной** ставит отметку, которую можно снять.
- Для уведомления Android нужно разрешение уведомлений. При долгом фоновом прослушивании проверьте ограничения батареи для приложения.
- Отказ Google: проверьте Drive API, тестового пользователя, разрешения и повторите подключение.
- Не входит Android: проверьте пакет, SHA-1 фактической подписи, сервисы Google Play и проект Cloud. Одного импорта Desktop JSON недостаточно.
- Пустая библиотека телефона: задайте свою папку перед сборкой, проверьте доступ к ней через браузер, переподключите аккаунт и проверьте вкладки музыки, книг и неразобранного.
- Позиции различаются: проверьте аккаунт, проект, сеть, состояние синхронизации, ID исходного файла и часы. Поставьте паузу и синхронизируйте оба устройства вручную.
- Нет описания: подтверждённые метаданные есть не для каждого файла. Приложение не сочиняет аннотации для заполнения пропусков.

## 7. Сборка Windows и проверки

~~~powershell
npm ci
npm test
npm start
npm run build:win
~~~

Установщик появляется в dist. Сохраняются новый и предыдущий установщики; библиотека пользователя не удаляется. После сборки можно запустить **node scripts/personal-packaged-smoke.cjs**. Защищённое хранилище Windows зависит от платформы. Результаты и ограничения проверок: [VERIFICATION.md](VERIFICATION.md).
