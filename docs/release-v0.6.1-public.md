## English

Public Windows0.6.1 installer and Windows/Android source with English and Russian documentation.

- Personal local/Google Drive music and audiobooks, folders, queue, playback controls and progress sync.
- Original neutral icon; no personal audio, account data, OAuth JSON or private Drive folder IDs.
- Android0.4.1 is provided as source. Configure your own folder, build the APK and register its package/SHA-1 in your Google project.
- Start here: [English guide](https://github.com/q9605514048-prog/MeguBoom/blob/main/docs/en/USER_GUIDE.md).

Verification:41 Node tests and41 Android JVM tests passed. Android lint/build and Windows packaged local playback/settings smoke checks passed. Real Google login and physical-device cross-platform sync require your own project, account and consent. The Windows installer is unsigned.

## Русский

Публичный установщик Windows0.6.1 и исходники Windows/Android с документацией на русском и английском.

- Личная музыка и аудиокниги, локальные файлы/Google Диск, папки, очередь, управление и общий прогресс.
- Оригинальная нейтральная иконка; нет личного аудио, данных аккаунта, OAuth JSON и ID личной папки.
- Android0.4.1 опубликован в исходниках: задайте свою папку, соберите APK и зарегистрируйте пакет/SHA-1 в своём проекте Google.
- Начните с [русской инструкции](https://github.com/q9605514048-prog/MeguBoom/blob/main/docs/ru/USER_GUIDE.md).

Проверено:41 тест Node и41 JVM-тест Android; lint/сборка Android; запуск, локальное воспроизведение и восстановление настроек Windows. Настоящий вход Google и синхронизация между физическими устройствами требуют вашего проекта, аккаунта и разрешений. Установщик Windows без цифровой подписи.
